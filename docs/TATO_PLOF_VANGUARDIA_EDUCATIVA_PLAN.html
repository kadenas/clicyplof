01

VANGUARDIA EDUCATIVA / 7 PRINCIPIOS

01 / CAUSAL LEARNING

EL CONCEPTO MUEVE LA TRAMA

Si quitamos el aprendizaje, el problema ya no puede resolverse. “Rojo” no se recita: identificar rojo abre la caja correcta.

02 / PREDICTION

ANTES DE EXPLICAR, HACER PENSAR

El niño recibe información suficiente para anticipar. La pregunta no examina: activa una hipótesis.

03 / TRANSFER

DE LA PANTALLA AL MUNDO

Cada episodio debe permitir una acción real después: ordenar, contar, comparar, buscar, turnarse, probar.

04 / JME

DISEÑADO PARA SER COMPARTIDO

Incluimos “puentes de conversación”: una frase o acción que el adulto pueda continuar fuera de la pantalla.

05 / PRODUCTIVE FAILURE

EQUIVOCARSE ES ACCIÓN

Tato y Plof prueban, fallan, comparan y corrigen. No hay sermón: hay evidencia visible.

06 / REPLAY VALUE

REPETIR PARA DOMINAR

La segunda visión no es consumo duplicado: permite anticipar antes, nombrar antes y detectar el patrón.

07 / LOW-NOISE DESIGN

CURIOSIDAD > SOBREESTIMULACIÓN

Pocos focos simultáneos. Silueta clara. Audio legible. Movimiento motivado por la historia.

GO / NO-GO CHECK

REJECT EPISODE IF
  • el aprendizaje puede quitarse sin afectar la historia
  • hay más de un problema central
  • la pregunta no se puede responder con lo visto
  • el error existe solo para rellenar tiempo
  • hay estímulo sin función narrativa
  • el final no resuelve lo planteado
GREENLIGHT IF
  • el niño entiende qué quiere el personaje
  • puede anticipar algo antes del final
  • el concepto cambia la acción
  • hay una emoción legible
  • se puede repetir con más dominio
  • existe una pequeña transferencia fuera de pantalla
